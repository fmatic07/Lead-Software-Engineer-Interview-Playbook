# Cloud-Native AWS

> AWS services and cloud architecture patterns for enterprise Java workloads.

---

## Purpose

Demonstrate AWS fluency expected at companies running production Java on cloud — compute, storage, networking, security, and managed services that reduce operational burden.

---

## Topics Covered

- [ ] Compute: EC2, ECS/EKS, Lambda — selection criteria
- [ ] Storage: S3, EBS, EFS — use cases and cost
- [ ] Database: RDS (MySQL/PostgreSQL), Aurora, DynamoDB
- [ ] Networking: VPC, subnets, security groups, ALB/NLB
- [ ] IAM roles, policies, and least-privilege access
- [ ] Secrets Manager, Parameter Store, KMS
- [ ] CloudWatch, X-Ray, and observability stack
- [ ] Cost optimization and Well-Architected Framework pillars
