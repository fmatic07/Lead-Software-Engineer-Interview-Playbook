# Feedback Tracker

> External feedback collected from mock partners, mentors, and interview debriefs.

---

## Purpose

Centralize feedback from others — mock interview partners, mentors, recruiters, and post-interview debriefs — and track which feedback you have acted on vs. which remains open.

---

## Topics Covered

- [ ] Feedback source and date
- [ ] Category (technical, communication, presence, content)
- [ ] Specific feedback received
- [ ] Action taken
- [ ] Verification (did the fix work in next mock?)
- [ ] Recurring themes across feedback sources

---

## Progress Checklist

- [ ] Collected feedback from at least 2 external sources
- [ ] Categorized and prioritized feedback items
- [ ] Acted on top 5 feedback items
- [ ] Verified improvements in subsequent mocks
- [ ] No unresolved critical feedback before real interviews
