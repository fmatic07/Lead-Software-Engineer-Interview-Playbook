# Self-Assessment Rubric

> Objective scoring criteria to evaluate readiness before real interviews.

---

## Purpose

Remove guesswork from "am I ready?" — score yourself across the dimensions enterprise panels evaluate and identify gaps with specificity, not vague anxiety.

---

## Topics Covered

- [ ] Technical depth scoring (Java, Spring, databases)
- [ ] System design scoring (structure, tradeoffs, communication)
- [ ] Architecture scoring (patterns, cloud, production awareness)
- [ ] Leadership scoring (stories, influence, decision-making)
- [ ] Behavioral scoring (STAR quality, senior-level scope)
- [ ] Communication scoring (clarity, concision, structure)
- [ ] Overall readiness threshold

---

## Progress Checklist

- [ ] Scored all dimensions (1–5 scale)
- [ ] Identified dimensions below threshold (≤3)
- [ ] Created improvement plan for weak dimensions
- [ ] Re-scored after mock interviews
- [ ] All dimensions ≥4 before scheduling real loops
