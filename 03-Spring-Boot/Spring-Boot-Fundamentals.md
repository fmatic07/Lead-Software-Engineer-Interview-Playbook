# Spring Boot Fundamentals

> Auto-configuration, lifecycle, and production-ready Spring Boot applications.

---

## Purpose

Demonstrate mastery of Spring Boot as the foundation of enterprise Java services — not just annotation usage, but how the framework boots, configures, and fails in production environments.

---

## Topics Covered

- [ ] Application context and bean lifecycle
- [ ] Auto-configuration mechanics and conditional beans
- [ ] Externalized configuration (profiles, `@ConfigurationProperties`, secrets)
- [ ] Actuator endpoints and health checks
- [ ] Graceful shutdown and readiness/liveness probes
- [ ] Structured logging and correlation IDs
