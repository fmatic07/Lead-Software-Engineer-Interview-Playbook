# Spring Security and JWT

> Authentication, authorization, and token-based security for REST APIs.

---

## Purpose

Prove you can design and implement secure API layers — the non-negotiable requirement for banking, telco, and government systems. Panels probe OAuth2 flows, JWT tradeoffs, and common security mistakes.

---

## Topics Covered

- [ ] Spring Security filter chain architecture
- [ ] Authentication vs. authorization
- [ ] JWT structure, signing, validation, and refresh token patterns
- [ ] OAuth2 and OpenID Connect integration
- [ ] Role-based and attribute-based access control
- [ ] CSRF, CORS, and common API security vulnerabilities
- [ ] Security in microservices (token propagation, service-to-service auth)
