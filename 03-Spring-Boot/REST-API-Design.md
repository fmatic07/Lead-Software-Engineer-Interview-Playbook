# REST API Design

> Contract-first APIs that survive versioning, scale, and cross-team consumption.

---

## Purpose

Articulate API design principles that enterprise teams enforce — consistency, error handling, pagination, versioning, and documentation. Full-stack depth includes how React/Next.js clients consume these contracts.

---

## Topics Covered

- [ ] REST maturity and resource modeling
- [ ] HTTP semantics (status codes, idempotency, safe methods)
- [ ] Request/response DTOs and validation (`@Valid`, custom validators)
- [ ] Pagination, filtering, and sorting patterns
- [ ] API versioning strategies (URL, header, content negotiation)
- [ ] Error response standardization (RFC 7807 Problem Details)
- [ ] OpenAPI/Swagger documentation and contract testing
