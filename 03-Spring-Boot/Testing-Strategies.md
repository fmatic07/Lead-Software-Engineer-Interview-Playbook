# Testing Strategies

> Test pyramid, integration testing, and quality gates for Spring services.

---

## Purpose

Demonstrate that you build quality into the delivery pipeline — unit tests, integration tests with Testcontainers, contract tests, and the judgment to know what to test at each layer.

---

## Topics Covered

- [ ] Test pyramid and testing trophy for microservices
- [ ] JUnit 5, Mockito, and AssertJ patterns
- [ ] `@WebMvcTest`, `@DataJpaTest`, `@SpringBootTest` slice tests
- [ ] Testcontainers for MySQL/PostgreSQL integration tests
- [ ] Contract testing (Spring Cloud Contract, Pact)
- [ ] Test coverage vs. meaningful coverage debate
- [ ] CI integration and test performance at scale
