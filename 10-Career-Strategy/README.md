# Career Strategy, Offer Negotiation & First 90 Days

> From recruiter contact through offer decisions to credibility in the first 90 days — for Senior, Lead, Tech Lead, and Architect candidates.

---

## Purpose

This module prepares experienced engineers to evaluate opportunities strategically, negotiate professionally, transition cleanly, and establish credibility quickly. It assumes you have completed Modules 01–09.

**Not** a salary-only guide — compensation is one chapter in a full hiring-lifecycle system.

## Suggested Order

1. Planning → Recruiter habits (00–01) before active loops heat up.  
2. Negotiation + evaluation + multi-offer (02–04) when finals approach.  
3. Resignation + background (05–06) after accept.  
4. 30-60-90 + credibility (07–08) before day one.  
5. Growth + reflection (09–10) as ongoing operating system.
